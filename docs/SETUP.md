# Как запустить бота на своём канале

Ничего сложного: просто иди сверху вниз и делай по одному пункту. Отдельный аккаунт для бота не нужен: бот пишет от твоего аккаунта Twitch. Работает на Windows и Mac.

**Что такое «терминал»?** Это окно, куда вставляют команды.
- Windows: нажми кнопку «Пуск», напиши `PowerShell` и открой.
- Mac: нажми `Cmd + Пробел`, напиши `Терминал` и нажми Enter.

Чтобы выполнить команду: скопируй её, вставь в терминал и нажми Enter. Жди, пока снова появится строка, где можно писать.

---

## Шаг 1. Поставь программы

Скачай и установи (во всех окнах жми «Далее» / «Next»):

1. Node.js, версия LTS: https://nodejs.org
2. Git: https://git-scm.com
3. OBS Studio: https://obsproject.com

После установки **закрой терминал и открой заново**. Потом вставь:

```
corepack enable
```

Если ничего не написало, всё хорошо.

## Шаг 2. Скачай проект

Вставь по очереди, каждая команда отдельно. Первая скачает проект:

```
git clone https://github.com/LuckyFoxCode/fox-sphere-nuxt.git
```

Вторая зайдёт в папку проекта:

```
cd fox-sphere-nuxt
```

Третья поставит нужное (займёт пару минут):

```
pnpm install
```

## Шаг 3. Создай приложение на Twitch

1. Открой https://dev.twitch.tv/console и войди своим аккаунтом.
2. Нажми **Applications**, потом **Register Your Application**.
3. Заполни:
   - **Name**: любое имя.
   - **OAuth Redirect URL**: вставь это:

     ```
     http://localhost:3000/auth/twitch/callback
     ```

   - **Category**: Chat Bot.
   - **Client Type**: Confidential.
4. Нажми **Create**, потом **Manage** у своего приложения.
5. Скопируй **Client ID** и запиши куда-нибудь.
6. Нажми **New Secret**, скопируй **Client Secret** и тоже запиши. Он показывается только один раз.

## Шаг 4. Настройки

Сделай файл настроек. Windows (PowerShell):

```
Copy-Item .env.example .env.production
```

Mac:

```
cp .env.example .env.production
```

Теперь нужны две случайные строки. Вставь эту команду и скопируй то, что она напечатала:

```
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Вставь ту же команду ещё раз: получится вторая, другая строка.

Открой файл `.env.production` в папке `fox-sphere-nuxt` (подойдёт Блокнот). Найди эти строки и замени значения справа от `=`, остальное не трогай:

```
NITRO_PORT=3000
DATABASE_URL=file:./data/prod.db
BOT_ENABLED=true
OVERLAY_URL=http://localhost:3000
COMMAND_PREFIX=!
TWITCH_BOT_REDIRECT_URI=http://localhost:3000/auth/twitch/callback
TWITCH_CHANNEL_NAME=твой_логин_маленькими_буквами
TWITCH_CLIENT_ID=сюда_Client_ID
TWITCH_CLIENT_SECRET=сюда_Client_Secret
INTERNAL_SECRET=первая_случайная_строка
ADMIN_SESSION_SECRET=вторая_случайная_строка
```

Ещё два правила:
- `TWITCH_USER_ID` пока оставь пустым.
- `TWITCH_BOT_ID` оставь пустым совсем. Так бот работает от твоего аккаунта.

Если у тебя **Mac**, добавь в конец файла ещё одну строку (музыкальный виджет работает только на Windows):

```
MUSIC_ENABLED=false
```

Сохрани файл.

## Шаг 5. Запусти

Вставь по очереди, каждая команда отдельно, и дожидайся конца:

```
pnpm db:push:prod
```

```
pnpm db:seed:prod
```

```
pnpm build
```

```
pnpm start
```

После последней команды окно будет «занято»: это нормально. **Не закрывай его**: пока оно открыто, бот работает.

## Шаг 6. Войди через Twitch (нужно один раз)

1. Открой в браузере:

   ```
   http://localhost:3000/auth/twitch/login
   ```

2. Войди своим аккаунтом Twitch. На странице появится `id` и число: это твой Twitch ID. Скопируй число.
3. Открой `.env.production`, впиши число после `TWITCH_USER_ID=` и сохрани.
4. Вернись в окно терминала и нажми `Ctrl + C`, чтобы остановить бота. Запусти заново:

   ```
   pnpm start
   ```

5. Открой ссылку из пункта 1 и войди **ещё раз**. Второй вход нужен, чтобы появились все права.
6. Останови бота (`Ctrl + C`) и снова запусти `pnpm start`.
7. Напиши в чате своего канала `!coins`. Если бот ответил, всё работает.

## Шаг 7. Добавь картинку в OBS

В OBS открой нужную сцену и сделай так:

1. В блоке **Источники** нажми **+** и выбери **Браузер** (Browser).
2. В поле **URL** вставь:

   ```
   http://localhost:3000/overlay/scene
   ```

3. **Ширина** 1920, **Высота** 1080.
4. Поставь галочку **Control audio via OBS** (чтобы звук алертов был в микшере).
5. Нажми **OK**.

Это всё: в этой одной сцене уже есть чат, герои, алерты, шапка стрима, рулетка, профиль, лотерея, магазин, таймер и «сейчас играет». Больше ничего добавлять не надо.

## Шаг 8. Админка

Открой в браузере:

```
http://localhost:3000/admin
```

Войди тем же аккаунтом. Там зрители, тексты команд (замени ссылки-заглушки на свои), язык бота и настройки.

## Каждый день

Запустить бота: открой терминал, зайди в папку и запусти:

```
cd fox-sphere-nuxt
```

```
pnpm start
```

Остановить: `Ctrl + C`.

## Если что-то не так

| Что случилось | Что сделать |
|---|---|
| Twitch пишет `redirect_mismatch` | Адрес в консоли Twitch и `TWITCH_BOT_REDIRECT_URI` должны совпадать буква в букву |
| «Не тот аккаунт» после входа | Ты вошёл в Twitch другим аккаунтом: открой ссылку входа в окне инкогнито |
| При запуске написано `... не задан` | Одна из строк в шаге 4 не заполнена |
| Бот молчит в чате | Проверь `BOT_ENABLED=true`, что префикс `!` и что окно с `pnpm start` открыто |
| Нет фолловов и наград | `TWITCH_USER_ID` пуст или не было второго входа (шаг 6) |
| В админку не пускает | `ADMIN_SESSION_SECRET` пуст или короче 32 символов |
| Пишет «порт занят» | Добавь в `.env.production` строку `SOCKET_PORT=` с другим числом |
| Всё задвоилось в OBS | В OBS должна быть только одна `/overlay/scene`, лишние источники удали |

## Хорошо знать

- Награды за баллы, подписки и Bits Twitch отдаёт только аффилиатам. Без этого такие алерты просто не придут.
- Виджет «сейчас играет» работает только на Windows, с любым браузером или плеером.
- Обновить проект: останови бота и выполни по очереди `git pull`, `pnpm install`, `pnpm db:push:prod`, `pnpm build`, `pnpm start`.
- Хочешь двигать виджеты по отдельности (чат отдельно, герои отдельно): вместо `/overlay/scene` добавь отдельные источники, список адресов есть на `http://localhost:3000/`. Общую сцену и отдельные источники вместе не добавляй.
- Хочешь пробовать и не трогать боевой чат: сделай `.env.development` (порт 3001, `BOT_ENABLED=false`, префикс `!t`, второй Redirect URL `http://localhost:3001/auth/twitch/callback`) и запускай `pnpm dev`.
- Если позже заведёшь отдельный аккаунт для бота: впиши его id в `TWITCH_BOT_ID`, войди под ним на `/auth/twitch/login` и под собой на `/auth/twitch/broadcaster/login`, и дай боту `/mod`.
